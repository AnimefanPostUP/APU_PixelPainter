A Drawing Addon for Blender 4.2,
specialized on drawing low Resolution, Pixel Art style Textures within Blender with several Helpfull Tools, Brushes, Custom Colorpicker/Selctors, Copy Pasting Tools etc.

DISCLAIMER: Coded primarely with Claude, partially by Hand, my main goal was just to have a drawing tool and UI that is easier to use espacially for the niche usecase of Pixelart

<p>  Control: Colorpicker  </p>
<p>  Alt:       Linedrawer </p>
<p>  Shift:     Smoothing (LMB) | Eraser (RMB) </p>
<p>  W:         Toolmenu </p>
<p>  W+Shift:   Blendmodes </p>
<p>  E:         Color Select </p>
<p>  E + Shift: Strength, Modifier Alpha Menu </p>
<p>  Shift + 1-7 : Tool Selection (Quick) </p>

<p>  In Selection Mode </p>
<p>  Ctrl+C/V:   Copy and Pasting </p>
<p>  Shift:   Mirrored Scaling of Selection Rectangle </p>


In the Npanel theres Settings for Spacing!
It sets if drawing is just while moving or per pixel.

Additionally theres Settings for Adjusting if the Tools should use Shared Global Settings for Size, Strength, etc...
